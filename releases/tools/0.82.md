# Host Tools 0.82

## [0.82.1]

### ➕ Added

- Project the string-array inventory from successful `icp canister list --json`
  and the decimal-string cycle balance from one successful status JSON object.
  Both accept caller-selected complete-input byte bounds, preserve unknown
  metadata and reject malformed, null, wrong-type or repeated authority fields.
  Inventory order and repeated names are preserved for caller-owned handling.
- Public-only status omits cycles and returns an unknown balance rather than
  zero. Supplied balances retain the full `u128` range and accept ICP's Candid
  Display grouping (`1_000`) or ungrouped decimal. Invalid grouping, signs,
  whitespace, fractions and overflow refuse. No command, funding policy,
  fallback, credentials, capture mechanism or retry moves into Host.
- Protocol evidence is ICP CLI revision
  `805017f9f7eb1ec110d7095fc063aec1845bf2bc`, its canister `list.rs` and `status.rs`.
  Status calls Candid `Nat::to_string()`, whose display groups digits by three;
  no Candid dependency is added to the default decoder graph.
  [#335 — Share bounded ICP inventory and cycle decoding](https://github.com/dragginzgame/ic-tooling/issues/335)
  owns producer delivery and published-API adoption evidence. Source preparation
  alone does not establish registry availability or native host qualification.
