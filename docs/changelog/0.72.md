# IC Tooling 0.72

## 0.72.0 - Unreleased

### ⚠️ Breaking

Testkit's `WireCallSpec` limit fields and typed codec error causes now have IC Wire
0.9 identity. Consumers passing limits or matching those errors align their direct
Wire dependency to 0.9. The private probe uses the same selection. No compatibility
bridge is retained; request/reply bytes, admission budgets, typed refusals, method
context and one-shot behavior stay unchanged. Optional Wire endpoint integration
remains disabled. [#271](https://github.com/dragginzgame/ic-tooling/issues/271)
owns this public type alignment.

Package metadata stays 0.71.0. This isolated contribution does not copy the normal
checkout's separate pending Platform 0.10 adoption; the owner can integrate both
changes in the existing pending 0.72 release.
